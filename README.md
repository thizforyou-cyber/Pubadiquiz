# Pubadi Quest — UGC NET Public Administration

A mobile-friendly, gamified study app built with HTML, CSS and JavaScript.

## Included in this first version
- Quiz Arena with multiple-choice questions and answer explanations
- XP points, correct-answer total and daily five-question mission
- Mistake Review for missed questions
- Quick Recall flashcards
- Topic filters for Thinkers & Theories, Administrative Thought, Indian Administration, and Development & Governance
- Responsive phone and desktop layout

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Tap **Pages**.
3. Under build and deployment, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for the website URL to appear on the Pages settings screen.

## Question-source note
The sample questions are transcribed from the uploaded PDF titled **UGC NET Public Administration In English**, which credits Toppersexam.com. This is treated as a question bank, not as proof that every item is an officially verified previous-year question. Source references are shown in the quiz. Some extracted source formatting is imperfect, so verify ambiguous answer keys against the original PDF and prescribed study material. Explanations are short study notes added for revision.

Do not publish the full source PDF or reproduce a large part of a third-party question bank without permission.

## Add more questions
Edit app.js and add an item to the bank array. Each question needs a unique id, topic, question text (q), four options (o), zero-based answer index (a), source (src), and explanation (why).
